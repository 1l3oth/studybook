The Full Stack

Frontend, backend, infra, model — at a glance

Frontend

Next.js 16 (App Router, RSC), React 19, Tailwind CSS 4. State and data: Zustand, TanStack Query + Table. UI: shadcn/ui (new-york), Magic UI, React Hook Form.

Backend

NestJS 11, Mongoose/MongoDB, JWT auth, Scalar for OpenAPI docs. BullMQ runs every background job — translation-fill, embed, publish — nothing synchronous inside a request.

Infra

mongo:8 single-node replica set, redis:7 backing those three queues. Containerized api/web/worker images, hot-reloading, one docker compose up for the whole stack.

AI Model

Claude drafts wording, mocked behind a provider interface. OpenAI text-embedding-3-large at 2048 dimensions — a Matryoshka reduction from the 3072 default, near-full match quality for a third less storage. English and Korean are the two source languages.

AI Agent Workspaces · Orbit

Orbit: a task API built for machines

  • An MCP-native tool from the ground up — an agent talks to it the same way it talks to any other tool call, not through a UI built for humans first.
  • The primitive is the task claim: tasks.claim / next / renew / release / comment / create, plus dependency edges between cards.
  • Goal-scoped, but not only — Polyglot's key is goal-scoped, exactly one project's queue. Orbit itself also runs a global scope: create notes, goals, tasks and comments across the whole account, plus one global note not tied to any single project.
  • Talks to its own AI — a separate server lets an agent consult Gojo, Orbit's shipped AI assistant, not just its task store.

The Playbook

When to sync, and what to reach for

team-meeting

Two triggers: a Team Sync once all three have a Done task since the last one, or a Blocker Sync when all three read as blocked on the same or a related cause. Either way, an agent only requests it — main checks everyone's actually free and opens the room.

choose-the-instrument

Picks the right tool for a given step — the axis that actually discriminates, not just whatever field is easiest to query — so an agent reaches for the correct instrument instead of improvising one that only looks like it answers the question.

A2A

How they actually talk to each other

  • The identity card — every message opens with who's talking and where they stand: --- Name (role) --- / Status: .... No real-time presence indicator, so this is the only way to tell.
  • No push, only poll — there's no notification channel between agents. While a conversation is open, each one polls every 90 seconds, rereads the thread, replies if something needs one.
  • One coordinator forms the room — a sync is requested, never self-convened. Main confirms everyone's free and opens it, so three agents can never spawn three meetings for the same trigger.
  • Closes on quiet, not a clock — ends when a full poll round passes with no new comment. The closer posts the marker, their identity card, and what was decided.

Hands On The Wheel

One command. Zero micromanagement.

  • Start it — /loop /work api (or web, qa) and Max, Ivy or Sam takes it from there.
  • It paces itself — checks back on its own schedule, never stops on its own. Only the user does.
  • Questions land on the card, not in chat — an @main comment with the default it's taking, answered whenever it's convenient.
  • Gates stay human — an agent can finish every task under a milestone and still can't open the next one. Only main closes the gate.
